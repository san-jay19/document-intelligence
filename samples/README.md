# Sample API Outputs

These are **sanitized representative examples** of the JSON structure returned by FinSight AI for the four supported financial document types.

They are provided for documentation/demo purposes and are not intended to reproduce every field from a specific source document.

Files:
- `invoice.json`
- `balance_sheet.json`
- `profit_and_loss.json`
- `cash_flow_statement.json`

The samples demonstrate:
- flexible AI-extracted fields and tables
- evidence and confidence
- financial validation checks
- calculated vs reported values
- variance
- PASS / FAIL / NOT_APPLICABLE behavior
- period-aware statement validation
